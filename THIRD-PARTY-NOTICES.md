# Third-party content

This file is voluntary. MIT does not require a notice file — it is here because
this plugin's whole subject matter is other people's work, and a reader of the
package should be able to see that without opening a browser.

## The skills

The skills this plugin browses and installs are **not part of this project** and
are **not covered by its MIT licence**.

Each skill is created and published by its own author on SkillHub
(https://skillhub.cn). Copyright in every skill belongs to that author, and each
skill is governed by whatever licence its own `SKILL.md` declares. Installing a
skill downloads it from SkillHub at that moment; this project does not host,
mirror, relicense or resell any skill content.

## What this plugin does handle

Index metadata retrieved from SkillHub's public API — names, descriptions,
versions, download and save counts, category, the third-party security-scan
verdicts, and file listings — together with the text of an individual file,
fetched on request for the preview shown before you install. That metadata is used
only to display and identify skills, and links back to the original pages on
SkillHub.
